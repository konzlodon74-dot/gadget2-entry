## What it does

`main.py` (Python 3, standard library only, no network) writes one original
roast line about the gadget I use every day — my smartwatch — to
`/output/entry.txt`. The line is validated against the competition gate
(1–200 UTF-8 characters, not only whitespace, single line) before writing,
and the file is re-read afterwards to verify its contents match exactly.

## The roast

> My smartwatch buzzes every hour to remind me to breathe, as if I'm the one whose battery dies by 6pm.

## Run

```sh
python3 main.py
```
